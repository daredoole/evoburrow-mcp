# Denon AVR-X1800H verified behavior

## Calibration preparation

Source: Denon AVR-X1800H owner’s manual. Evidence: manufacturer. Confidence: high. Applicability: AVR-X1800H.

Place the supplied microphone at seated ear height with its tip toward the ceiling. With a direct-mode subwoofer, enable direct mode. Otherwise Denon specifies approximately 10 o’clock volume, maximum crossover, low-pass filter off, and standby mode off for Audyssey setup.

## Manual changes after Audyssey

Source: Denon AVR-X1800H Manual Setup. Evidence: manufacturer. Confidence: high. Applicability: AVR-X1800H.

Changing distances, levels, or crossovers does not itself disable Audyssey or require a new Audyssey run. Enabling new speakers in Speaker Layout after calibration can make MultEQ XT, Dynamic EQ, and Dynamic Volume unavailable; rerun setup after layout changes.

## Subwoofer distance

Source: Denon AVR-X1800H Audyssey procedure. Evidence: manufacturer. Confidence: high. Applicability: AVR-X1800H.

Measured subwoofer distance may exceed physical distance because the subwoofer electronics add delay. Treat the stored value as timing compensation, not geometry.

## Network control

Source: Denon manuals. Evidence: manufacturer. Confidence: high. Applicability: compatible Denon/Marantz network receivers.

Network/IP Control must be Always On for standby access, with increased standby energy use. Protocol availability varies by model, so probe and query before relying on control.
