# Speaker placement and capability

## Dolby geometry

Source: Dolby Atmos Home Theater Installation Guidelines. Evidence: manufacturer. Confidence: high.

Use Dolby’s layout-specific diagrams for listener-level and height-channel angles. The MCP geometry tool uses broad windows only to flag likely placement errors; it does not replace the configuration drawing.

## Directivity and toe-in

Source: loudspeaker engineering practice. Evidence: heuristic. Confidence: high.

Choose toe-in using the loudspeaker’s horizontal directivity, off-axis response, room reflections, listening width, and tonal balance. There is no universally correct toe-in angle.

## Boundary interference

Source: room-acoustics engineering practice. Evidence: heuristic. Confidence: high.

Speaker and listener distance from boundaries creates cancellations that may be resistant to equalization. Test alternate positions before applying large boosts.

## Crossover choice

Source: electroacoustic engineering practice. Evidence: heuristic. Confidence: medium.

A crossover around 1.5-2 times a speaker’s anechoic F3 is a conservative starting point that can improve headroom. Final choice depends on distortion, compression, directivity, listening distance, subwoofer placement, and measured crossover-region summation.
